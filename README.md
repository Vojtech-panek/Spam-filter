# Spam Filter

A machine learning project implementing a spam classifier based on the examples and techniques presented in **Hands-On Machine Learning with Scikit-Learn, Keras & Pytorch** by Aurélien Géron.

## Project Goals

- Work with real-world email datasets
- Preprocess raw email messages
- Convert emails into numerical feature vectors
- Build a machine learning classification pipeline
- Evaluate the performance of the classifier
- Experiment with different preprocessing and classification techniques

## Dataset

The project uses the **Apache SpamAssassin Public Corpus**, containing examples of both spam and legitimate (`ham`) emails.
